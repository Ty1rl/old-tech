Round R audio contract — jam-6

AudioManager is the sole music owner. Call set_music_context(StringName):
  menu      menu.mp3, loop, normal pitch, plays through a paused tree
  intro     silence (narration is separate)
  encounter regular_combat.mp3, loop, smoothed world time/pitch and scrub fade
  boss      boss.mp3, loop, same world policy; use for ALL THREE bosses
  victory   victory.mp3, once, normal pitch, plays through a paused tree
Unknown contexts return false without replacing playback. Repeating the current
context is idempotent; leave/re-enter victory to replay it. Replacement stops the
old track immediately and coalesces deferred starts onto the latest context.
Master sound/zero-volume settings stop music; unmuting restarts selected music.
CombatFeedback supplies smoothed world pitch, freeze and foreground ducking. It
has six loop players and nine transient players, no music player. There is one
global Music and one global Voice player (17 native audio players with one arena).
The legacy arena set_music_playing(true) hook selects encounter from menu/intro
but preserves an explicit boss/victory context. Campaign owns semantic contexts.

Speech:
  say(event, priority=1, once=false) -> bool
  play_intro() -> bool (explicit only; once per begin_run)
  lesson(id), begin_run(), stop_dialogue() retain their previous call shapes.
  instruction_busy() -> bool covers current AND queued tutorial.* events.
  is_speaking(event:StringName) -> bool covers current AND queued matching event.
  speech_finished(event:StringName, interrupted:bool) is terminal exactly once
    for each ACCEPTED request, including queued requests cancelled before start.
Rejected/missing/malformed/empty/unavailable requests return false and create no
terminal obligation. Missing library, Master mute/zero volume or Voice mute/zero
volume bypass busy predicates immediately and cancel accepted speech next tick.
Once flags are consumed at playback start and reset by begin_run. Queue cap is3;
incidental barks never interrupt teaching; higher priority cancels current+queue.
Stop, restart, scene tree exit/change, unavailable audio and quit cancel with true.
Native completion emits false; a handoff starts queued speech before notification,
so instruction_busy stays true throughout an instruction chain. Explicit stop
clears the whole batch before callbacks, and rejects reentrant enqueue attempts
inside cancellation callbacks. Retry a new request after that cancellation call.
Pause holds speech and its busy state; resume continues it. Skip/restart/scene
exit/quit can cancel even while paused. Consumers must not wait for natural
completion while holding a pause indefinitely. Call stop_dialogue for explicit
skip. AudioManager handles close_requested with cancellation and a .25s mixer drain.
